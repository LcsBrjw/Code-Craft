Projet fil rouge du CEFIM pour les autofinancement : 

Créer un site de partage de ressources ayant un lien avec le développement et le design.
1) Wireframing en équipe entre tous les autofinancement 
2) Maquettage sur Figma
3) Frontend en HTML/CSS/JavaScript Vanilla
4) Réflexion autour de la structure de la base de données (MySQL, PostgreSQL, SQLite)


A venir : 
1) Création de l'API en Laravel
